## 跑起來

<Steps>

1. 建立專案。

   ```sh
   npx pi-roundtable init my-bot
   ```

2. 安裝依賴、啟動 PostgreSQL，並填寫 `.env`。

   ```sh
   cd my-bot
   bun install
   docker compose up -d
   cp .env.example .env
   ```

3. 檢查設定，然後啟動 bot。

   ```sh
   bunx roundtable doctor
   bunx roundtable start
   ```

</Steps>

`agents.ts` 裡的智慧體現在都有了自己的頻道。
在 Discord 輸入 `/roundtable help` 開啟控制面板。

## 先知道這些

- 為一位擁有者和一個 Discord 伺服器設計。
  你可以允許其他人與智慧體對話，但這樣的設定與風險由營運者自行承擔。
- 只支援 Bun。套件直接發佈 TypeScript 原始碼，不需要建置步驟。
- MIT 授權。
