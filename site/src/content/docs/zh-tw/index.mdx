## 開口要，它能開出新的 agent

你在伺服器的入口頻道，跟協調者（coordinator）說話。
想要什麼，直接講。

<Image src={agentCreate} alt="在 guide 頻道，使用者請 Guide 做一個記讀書筆記的 agent。Guide 回覆已經在新的 notes 頻道做好 Notes，它有提示詞、頭像，還有一個存連結的技能，而且已經開始做第一份工作。" />

新的 agent 會有自己的頻道、頭像和提示詞，馬上開始做第一份工作。
你不用改設定檔，也不用重啟。

圖裡的文字是 bot 的英文介面；把 `locale` 設成 `zh-TW`，bot 在 Discord 裡就會用中文。

## 它能做什麼

<CardGrid>
  <Card title="開 agent" icon="rocket">
    要研究員、編輯、家教都行。每一個住在自己的頻道，有自己的對話。
  </Card>
  <Card title="自己寫技能" icon="puzzle">
    agent 可以寫一個技能，連結給其他 agent。
    它也會在不同對話之間記住事情。

    把兩到六個 agent 放進同一個群組頻道。
    每則訊息，由它決定誰來回答。
  </Card>
  <Card title="幫你整理" icon="approve-check">
    請它封存某個 agent，或重新排頻道。
    不會真的刪掉，封存的頻道會保留歷史紀錄。
  </Card>
</CardGrid>

agent 之間可以互相交辦工作。
這裡是研究員把整理好的內容交給編輯。

伺服器裡有一則狀態訊息會自己更新，誰在忙什麼一目瞭然。

## 跑起來

<Steps>

1. 建立專案。

   ```sh
   npx pi-roundtable init my-bot
   ```

2. 安裝、啟動 PostgreSQL，然後填寫 `.env`。

   ```sh
   cd my-bot
   bun install
   docker compose up -d
   cp .env.example .env
   ```

3. 檢查設定，然後啟動 bot。

   ```sh
   bunx roundtable doctor
   bunx roundtable start
   ```

</Steps>

第一個 agent 就會出現在你的伺服器裡。
跟它打聲招呼，再請它開第二個。
輸入 `/roundtable help` 可以開啟控制面板。

## 如果你會寫程式

上面這些都不用寫一行程式。
想要更多的時候，再用 TypeScript 加外掛：每個 agent 都能呼叫的工具、斜線指令、HTTP 路由，或是你想換掉的某個部分。
外掛可以在沒有 Discord 和 PostgreSQL 的情況下測試。
看[寫一個外掛](/zh-tw/plugins/first-plugin/)。

## 先知道這些

- 它是為一位擁有者和一個 Discord 伺服器設計的。
  你可以讓其他人跟 agent 說話，但那樣的風險由你自己承擔。
- 只支援 Bun。套件直接發佈 TypeScript 原始碼，不需要建置。
