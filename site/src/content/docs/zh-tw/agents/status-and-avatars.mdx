## 狀態訊息

bot 在伺服器最上方維護一個 `#dashboard` 頻道，不屬於任何類別。
頻道裡有一則 bot 的訊息，訊息會自己更新。

<Image src={agentStatus} alt="一則 Discord 訊息，列出 Guide、Researcher、Editor 三個 agent 的頻道、模型，以及各自是閒置還是工作中。" />

重啟之後，bot 會找回這則訊息；你把它刪掉的話，bot 會再建一則。
bot 有 Pin Messages 權限時，會把訊息釘選起來；沒有這個權限，訊息照樣能用，bot 只會在 log 裡警告一次。

### 它顯示什麼

標題底下是「Updated」時間，使用你設定的時區，再來是外掛加進來的各行文字。
訊息上的字樣跟著 `locale` 走。
這一頁引用的是英文版；`locale` 設成 `zh-TW` 時，bot 會寫成中文，例如 `Idle` 是「閒置」，`Working` 是「工作中」，「2 queued」是「排隊 2」。

每個使用中的 agent 有一個區塊，內容是：

- 它的顯示名稱，以及頻道的連結。
- 它的模型和 thinking level。
- 它的狀態：`Idle`，或 `Working` 加上它工作所在的頻道，或排隊中的訊息數量。排隊數量會放在 Working 旁邊，例如「2 queued」。
- context window 用了多少，例如 `context 12k / 200k (6%)`。context 剛壓縮完時，會直接說明，數字在下一輪恢復顯示。
- 它有幾個排程，以及最後活動的時間；或是「No activity since startup」。

每個使用中的群組顯示：顯示名稱、頻道連結、成員和主持人、目前閒置還是有回覆進行中，以及最後活動時間。

清單太長、一則 Discord 訊息放不下時，區塊的結尾會標出被省略的項目數量。
已封存的 agent 和群組不會列出來。

### 什麼時候更新

有東西變動時訊息就會更新，例如一輪開始或結束、建立了 agent。Discord 限制訊息的編輯頻率，所以最多每 10 秒編輯一次。
它也每 5 分鐘更新一次，讓最後活動時間和 context 數字保持最新。

## 頭像

每個 agent 在 Discord 裡都用自己的名字和圖片發言。
每張圖片是 agent 的角色：由零件組合，由 bot 自己畫出，不經過圖片 provider。

- 新 agent 得到依職務建議的外觀：一個職業（wizard、knight、scholar、ranger 等共 24 種）配八種顏色之一。`agent_create` 可用 `class` 和 `color` 指定。
- 之後用 `agent_avatar` 工具改外觀：職業、顏色，或帽子、道具、髮型、體型、膚色等單一零件。沒提到的維持原樣，換職業時保留 agent 原來的顏色。
- owner 的個人檔案面板（`/profile`）有職業和顏色兩個下拉選單，作用相同。
- 新的圖片從 agent 的下一則訊息開始顯示。
- 0.23 之前就存在的 agent，第一次啟動時會得到一個角色，所以它們的 Discord 頭像會換一次。

bot 需要支援 SVG 的 `canvas`（librsvg）來畫圖，沒有的話 agent 伺服器不會啟動。`bunx roundtable doctor` 的 `characters` 檢查會確認這點。

<Aside type="note" title="繪製頭像已棄用">
用 `images` provider 繪製 agent 圖片、`avatar` 設定和 `avatarPrompt` 都已棄用且被忽略，1.0 移除。`images` 槽位仍供 `generate_image` 使用。
</Aside>

### 圖片從哪裡提供

bot 把頭像存在資料目錄裡，並在 `PUBLIC_URL` 的 `/avatars/` 底下提供。
Discord 從那裡取圖，所以這個位址必須能從網際網路連到這個行程。
