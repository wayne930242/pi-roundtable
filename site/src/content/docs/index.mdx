## Run it

<Steps>

1. Create a project.

   ```sh
   npx pi-roundtable init my-bot
   ```

2. Install, start PostgreSQL, and fill in `.env`.

   ```sh
   cd my-bot
   bun install
   docker compose up -d
   cp .env.example .env
   ```

3. Check the setup, then start the bot.

   ```sh
   bunx roundtable doctor
   bunx roundtable start
   ```

</Steps>

The agents in `agents.ts` now have their channels in your server.
Send `/roundtable help` in Discord to open the control panel.

## Good to know

- Built for one owner and one Discord server.
  Others can be allowed to talk to the agents, but that setup, and its risks, are the operator's.
- Bun only. The package ships its TypeScript source, so there is no build step.
- MIT licensed.
